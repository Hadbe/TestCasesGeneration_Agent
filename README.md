# QA Analysis & Test Case Generator

Turn a plain user story into a complete, structured QA package — test objective, scope, risks,
assumptions, clarifications, exploratory charters, coverage gaps, a recommendation, and a full
set of editable test cases — generated by an LLM and ready to review, export, or push straight
into Azure DevOps.

**Live demo:** https://tc-generation-agent.streamlit.app/

## What it does

Paste a user story and acceptance criteria, and the agent produces:

- **Executive summary, scope, risks, assumptions, and clarifications needed**
- **Test cases** across positive, negative, boundary, edge, and security categories — each with
  ID, title, priority, type, preconditions, steps, expected result, severity, and notes
- **Exploratory testing charters** and **coverage gaps**
- A final **recommendation**

## Features

- **Single story or batch mode** — queue several user stories and generate all of them in
  parallel instead of one at a time
- **Review and edit before export** — every test case is editable in the UI; edits are reflected
  in both the downloads and the saved run
- **Export to JSON or Excel**, formatted and ready to share
- **Push directly to Azure DevOps** — creates Test Case work items (with proper steps/expected
  results) linked to a new or existing User Story
- **Run History** — revisit and re-download any past generation (isolated per browser session)
- **Self-correcting generation** — if the model's output isn't valid JSON, it automatically
  retries with the parse error before giving up
- **Multi-language input** — works with user stories in languages other than English (e.g. Arabic)
- Hardened against prompt injection, Excel formula injection, and markdown link hijacking in
  LLM-generated content

## Tech stack

Python · [Streamlit](https://streamlit.io/) · [OpenAI API](https://platform.openai.com/) ·
openpyxl · Azure DevOps REST API

## Running it locally

```bash
pip install -r requirements.txt
```

Create a `.env` file in the project root:

```
OPENAI_API_KEY=your-openai-api-key

# Optional: enables the "Push to Azure DevOps" button
AZURE_DEVOPS_ORG=
AZURE_DEVOPS_PROJECT=
AZURE_DEVOPS_PAT=
```

Then run:

```bash
streamlit run app.py
```

## Project structure

| File | Purpose |
|---|---|
| `app.py` | Streamlit UI — single/batch generation, editing, downloads, Azure DevOps push, run history |
| `main.py` | Core generation logic — calls OpenAI, parses the JSON export, builds the Excel workbook |
| `azure_devops.py` | Azure DevOps REST API client for pushing test cases as linked work items |
| `prompts/system_prompt.txt` | The system prompt that defines the QA package format |
